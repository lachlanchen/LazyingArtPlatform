# Seated panda identity

The approved September 27, 2026 LazyingArt company mark is a seated, smiling panda holding bamboo. The complete source, transparent marks, favicon face derivative, native icon starters and rebuild script live in the [shared branding kit](https://github.com/lachlanchen/lachlanchen/tree/main/logos/panda-v1).

The header uses a transparent 256px PNG at 51 CSS pixels. Browser tabs use the face derivative; Apple home-screen and manifest icons use the full panda. The maskable icon has extra safe-area padding. `site.webmanifest` keeps browser display mode: this change does not claim an offline app or add a service worker.

The prior header image and original approved concept are retained in `artifacts/images/`. L & N, Bunko and EchoMind retain their own icons. Only the public directory is deployed; shared identity and payments are unchanged.
